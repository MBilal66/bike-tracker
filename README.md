# Bike Tracker — GitHub Pages PWA

1. Upload **all files in this folder** to the root of your GitHub repository.
2. GitHub → **Settings → Pages** → Deploy from branch → `main` → `/ (root)`.
3. Open the resulting **HTTPS** GitHub Pages URL in Chrome.
4. Wait for the page to fully load once while online.
5. In Chrome, use **Install Bike Tracker** from the address-bar install icon or Chrome menu.

Important: do not open `index.html` directly from your computer. PWA installation requires the HTTPS GitHub Pages site (or localhost during development).

The app stores its data in the browser's local storage. GPS requires location permission. Google Maps/Calendar features require internet access. Excel export uses the browser download API.
